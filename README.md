# ExoticSwitch — prototip uređaja

Živi prototip uređaja za svjetlo u terariju: ekran, četiri tipke (▲ OK ▼ ←) i terarij
koji pokazuje kako se svjetlo mijenja kroz dan (prati sunce odabranog staništa ili
ručni raspored).

Otvori na mobitelu ili računalu: https://dtitlic-create.github.io/exoticswitch-prototip/

Sve je u jednoj datoteci (`index.html`), bez servera i bez interneta.
